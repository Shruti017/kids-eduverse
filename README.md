# Kids Eduverse

An interactive learning website for young children, with activities for letters, numbers, colors, shapes, animals, rhymes, and quizzes. Parent accounts use an Express API and MongoDB Atlas to sync account data and a learning summary.

## Try the app

- [Live app — Production](https://kids-eduverse.vercel.app): the main public site.
- [Main branch deployment](https://kids-eduverse-git-main-shruti017s-projects.vercel.app): Vercel’s deployment alias for the `main` branch.
- [Deployment preview](https://kids-eduverse-picklwlhp-shruti017s-projects.vercel.app): preview for a specific Vercel deployment; this URL may change with future deployments.
